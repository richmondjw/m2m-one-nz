Security & Surveillance

Cellular connectivity for cameras, alarms, and access control.

Industrial-grade SIM cards and managed connectivity for IP cameras, alarm panels, intercoms, and access control systems across New Zealand. Built for sites where wired internet is unreliable or unavailable.

How it works

What this looks like with M2M One NZ.

Surveillance systems exist because something might go wrong. The last thing they should do is also go wrong themselves. M2M One NZ runs the cellular layer behind a lot of NZ's monitored sites: cameras with cellular failover, alarm panels with cellular primary, access control on Spark's LTE-M, with 24/7 monitoring on top.

  • Primary or failover: cellular as the only link, or as the resilience layer behind fibre.
  • IP cameras at the edge: 4G/5G uplink with pooled data, bandwidth alerts.
  • Alarm panel cellular: industrial-grade SIMs in alarm/intercom enclosures.
  • Static IP and VPN for back-to-control-room links.
  • 24/7 monitoring integration: M2M One control plane talks to your NMS.
  • NZ Privacy Act 2020 aligned operations for footage and metadata.
