M2M Control Centre

Real-time IoT management for your fleet.

The Control Centre is where you manage everything we do for you. Monitor SIM status, track data usage, diagnose connectivity issues, set threshold alerts, and automate plan changes across your entire fleet. Included free with every M2M One NZ account.

Features

What's in the Control Centre.

Real-time SIM status

Activation state, location, signal, session history per SIM.

Data usage tracking

Per-SIM and pool-level data usage, with daily and hourly granularity.

Threshold alerts

Configure alerts at 50/80/100% of allowance. Email or webhook.

Plan changes

Change a SIM's data plan instantly, with cost-impact preview.

Diagnostics

Connection logs, last-seen, attached cell info, RF metrics.

REST API

Full API for SIM lifecycle, usage queries, alerts. OAuth 2.0.

Access

Sign in or request access.

Existing customers can sign in at the Control Centre login page. New customers, ask your account manager for credentials, or contact us.
